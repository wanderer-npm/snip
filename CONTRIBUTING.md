# contributing to snip

thanks for checking it out.

1. fork + clone
2. `cp .env.example .env` and `npx prisma db push`
3. `npm install` and `npm run dev`
4. make your change, keep it simple
5. `npm run typecheck` should pass
6. open a PR with what + why

no big framework swaps without an issue first. bug fixes + small features merge fastest.
